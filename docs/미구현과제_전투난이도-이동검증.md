# 미구현 과제 — 전투 난이도 판단 및 이동 검증

- 상태: **미구현 / 검증 보류**
- 등록일: 2026-09-25
- 관련: `COMBAT_PATCH_NOTES.md`, `docs/TextRAG 전투 시스템 개편 통합 기획안 v1.13.md`

## 문제

현재 전투 난이도 표시는 실제 자동사냥 전체를 대표하지 않는다.

- 기존 난이도 시뮬레이션은 주로 순수 평타 기준이며 스킬·버프·포션·자동회복을 충분히 반영하지 않는다.
- 현재 거리/이동 모델은 직업별 초기 거리와 단순 접근(`distance--`) 중심이라 원작의 무기·스킬 사거리, 몬스터 공격/추격 범위를 충분히 검증한 모델이 아니다.
- 따라서 현 난이도 판정값을 근거로 사냥터 자동 이동·적응형 이동을 실행하면 안 된다.

## 구현 전제

1. `combatRecords` 실제 전투 표본을 충분히 축적한다.
2. 난이도 지표를 실제 전투 기준으로 정의한다.
   - 사망/귀환률
   - 평균·최악 HP 손실
   - 포션 및 소모품 소모량
   - 처치시간/턴수
   - EXP·JEXP·제니 효율
   - 수동 개입 빈도
3. 플레이어 공격거리의 근거를 직업이 아니라 무기/스킬 사거리 중심으로 재검토한다.
4. 몬스터 AttackRange / SkillRange / ChaseRange 및 이동 가능 여부를 원작 데이터와 연결한다.
5. 접근·추격·공격 가능 거리의 브라우저 E2E 회귀검사를 만든다.
6. 위 검증이 끝난 뒤에만 난이도 판정 → 사냥터 이동 정책을 설계한다.

## 완료 조건

- 동일 캐릭터·동일 사냥터 반복 전투에서 난이도 판정이 실제 결과와 일관되게 대응한다.
- 근접/원거리/마법 직업에서 초기 거리, 접근, 공격 가능 거리 회귀 테스트를 통과한다.
- 고정형/이동형 몬스터 및 MVP/슬레이브 조우에서 이동 규칙을 검증한다.
- 자동 이동은 검증된 난이도 지표와 최소 표본수 조건을 만족할 때만 동작한다.

## 현재 판정

**구현하지 않는다.** 현재 전투 난이도 표시는 참고용으로 유지하고, 자동 이동 판단에는 사용하지 않는다. 충분한 `combatRecords` 표본과 거리 시스템 검증 이후 별도 구현한다.
