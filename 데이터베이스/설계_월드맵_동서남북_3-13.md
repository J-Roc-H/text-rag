## 0. 결정 사항 요약

| 항목 | 결정 |
|---|---|
| 구조 | `connected` 유지 + `dirs:{north,south,east,west}` 필드 **추가** (하이브리드) |
| 연결 5개+ 문제 | 원작처럼 **허브 필드를 방향별로 분할** (프론테라 평원 4분할 등) |
| 던전 | 1차 방향키 대상 **제외** — 진입은 기존 모달, 필드에 입구 주석만. 층간 ↑↓는 2차 |
| 배편·특수 이동 | 로컬라이징 투어(아마쯔·쿤룬·용지성·포트말라야), 발할라, 차원 균열 경유 이세계 — dirs 제외, 모달 전용 |
| 입력 | ←→↑↓ 방향키 (전투 중·모달 열림·입력 포커스 시 무시) + 나침반 UI 클릭(모바일 대응) |
| 나침반 UI | 지도 모달 내 배치안 (구현 시 확정) |
| 이동 처리 | `goDirection(dir)` → 기존 `tryMove(n)` 재사용 (던전 잠금·전투 이탈 로직 무료 획득) |

## 1. 필드 분할안

### 1-1. 프론테라 평원 → 4분할 (필수 — 연결 6개)

현재: `"monsters":[1,2,3,4,5,6,10,12,13,14,15,46]`, Lv1~10, MVP 없음

| 신규 맵 | Lv | monsters (ID) | 원작 근거 | 연결 |
|---|---|---|---|---|
| **프론테라 남쪽 평원** | 1~5 | 1포링, 2루나틱, 3파브르, 4푸파, 5드롭프스, 6촌촌 | prt_fild08 (포링 초보존) | N프론테라 / S이즈루드 / W모로크 사막 동부 |
| **프론테라 서쪽 평원** | 4~12 | 10윌로우, 12픽키, 14로커 | prt_fild00~02 (게펜 방면) | E프론테라 / W게펜 필드 |
| **프론테라 동쪽 평원** | 9~18 | 14로커, 15만드라고라, 13스모키 | prt_fild03 (페이욘 방면) | W프론테라 / S페이욘 숲 |
| **프론테라 북쪽 평원** | 15~25 | 13스모키, 15만드라고라, 46아르고스 | prt_fild05~07 (북부 상위) | S프론테라 / N묘르닐 산맥 · 미궁 숲 입구 |

- ⚠검수: 몬스터 배분 — 로커/스모키/만드라고라를 2개 맵에 중복 배치했음 (맵당 최소 3종 확보 목적)
- 북쪽 평원 N→묘르닐 산맥 신설로 알데바란 북부 루트가 생김 (원작 prt_fild→mjolnir 부합). 기존 게펜 경유 루트도 유지
- 미궁 숲(던전) 입구를 평원에서 **북쪽 평원**으로 이전 (원작 prt_maze는 북서부)

### 1-2. 모로크 사막 → 2분할 (권장 — 소그라트 사막 광역 재현)

현재: `"monsters":[9,21,60,61,68,69,123,124,125]`, Lv15~40, MVP 198 프리오니

- ⚠검수: 명칭 "소그라트 사막"(원작명) vs "모로크 사막 동부/서부" — 원작명 권장

### 1-3. 페이욘 숲 → 2분할 (선택 — 보류 가능)

현재: `"monsters":[13,34,35,36,39,40]`, Lv15~40, MVP 196 에드가

- 분할 보류 시: 기존 페이욘 숲에 dirs만 부여 (N프론테라 동쪽 평원 / S페이욘 / E알베르타)

## 5. 기존 데이터 버그 발견 (설계 중 실증)

- **알베르타 → 페이욘 숲 편도 연결**: 알베르타의 connected에는 "페이욘 숲"이 있으나 페이욘 숲의 connected에는 "알베르타"가 없음 → 현재도 페이욘 숲에서 알베르타로 못 감. 구현 전이라도 핫픽스 가능. **정합성 자동 검증기가 필요한 이유의 실례**

## 6. 스키마 · 구현 메모

```json
"프론테라 남쪽 평원": {
  "level":"1~5", "type":"필드", "emoji":"🌿",
  "connected":["프론테라","이즈루드","소그라트 사막 동부"],
  "dirs":{"north":"프론테라","south":"이즈루드","west":"소그라트 사막 동부"},
  "monsters":[1,2,3,4,5,6], "safe":false
}
```

- `dirs`는 `connected`의 부분집합이어야 함 (검증기 규칙 ②)
- 2-9 구역 시스템과 양립: 분할 맵도 `getZones()` 자동 적용 (몬스터 종수 줄면 구역 수 자동 축소)
- 검증기 규칙: ① 상호성 ② dirs⊆connected ③ 맵명 오탈자 ④ 고아 맵(어디서도 도달 불가) ⑤ hasMvp 승계 확인

### 구현 단계 (착수 시)

1. 이 문서 검수 반영 → db-maps 개편 (분할 맵 추가 + 전 맵 dirs)
