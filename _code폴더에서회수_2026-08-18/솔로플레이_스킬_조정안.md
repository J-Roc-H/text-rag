# 솔로 플레이 전환 검토 — 멀티/공성 의존 스킬 조정 가이드

> 기준: 파티 없음 · PvP 없음 · 공성전 없음 · 아이들 RPG 솔로 진행  
> 레퍼런스: `RO_스킬_원작_레퍼런스_v14.md` (1~20번 + 6.5 하이위저드)

## 분류 기준

| 구분 | 정의 |
|------|------|
| **A. 완전 제거** | 솔로에서 기능 자체가 성립하지 않고 재해석 여지도 없음 |

## A. 완전 제거 (4종)

| 직업 | 스킬 | 원작 기능 | 제거 이유 |
|------|------|-----------|-----------|
| 상인 | 노점 개설 (MC_VENDING) | 캐릭터를 노점 상태로 전환, 다른 플레이어가 구매 | 구매자인 다른 플레이어가 존재하지 않음 |
| 크루세이더 | 성체강복 (PR_BENEDICTIO) | 같은 자리의 프리스트 2인이 파티원 전체 무기/방어에 Holy 부여 | "같은 자리 프리스트 2인" 조건 자체가 불가 |
| 헌터 | 토키 박스 (HT_TALKIEBOX) | 맵에 말하는 박스를 설치해 지나가는 플레이어에게 메시지 전달 | 지나가는 플레이어가 없음; 아이들 RPG에 의미 없음 |
| 로그 | 클로즈 컨파인 (RG_CLOSECONFINE) | 대상 플레이어를 잡아 둘 다 이동 불가 (상대가 공격해야만 해제) | 상호작용 상대(플레이어)가 없음; 몬스터 대상 재설계도 원작 의도와 지나치게 달라짐 |

## B. 메커니즘 재설계 (12종)

### B-1. 파티원 보호/부활 → 자기 생존기

| 직업 | 스킬 | 원작 | 솔로 변환 제안 |
|------|------|------|----------------|
| 크루세이더 | **헌신** (CR_DEVOTION) | 파티원 1인에게 헌신, 그 파티원이 받는 피해를 크루세이더가 대신 받음 (MaxHP의 12%까지) | **자기 방어 버프**: "N초 동안 받는 피해 -X%". 레벨이 올라갈수록 감소율과 지속 시간 증가. 아이들 RPG의 탱킹 로테이션 쿨다운 스킬로 적합 |
| 프리스트 | **희생** (PR_REDEMPTIO) | 자신이 죽으면서 파티원 전체를 HP 50%·EXP 1% 손실로 부활 | **죽음의 순간 생환**: "일정 확률(또는 쿨타임 방식)로 사망 직전에 HP를 1로 유지하고 생존". 패시브로 구현하거나 사용 시 발동 대기 상태 진입 |
| 프리스트 | **리저렉션** (ALL_RESURRECTION) | 사망한 파티원 부활 (HP 10~80%) | **즉시 부활 아이템 대체** 또는 "사망 시 현재 맵에서 HP X%로 자동 부활 한 번(쿨타임 있음)". 복사 계열 정체성인 "생명 관련 마법"은 유지됨 |

### B-2. 앙상블 → 고위력 솔로 스킬 변환 (8종)

원작에서는 바드+댄서가 동시에 같은 셀에서 시전해야 발동하는 합주(앙상블). 솔로에서는 "바드 또는 댄서가 쌓은 기를 방출하는 강력한 단독 스킬"로 재해석. 시전 비용(SP)은 원작보다 높게 설정하거나 쿨타임 추가 권장.

| 앙상블 스킬 | 원작 효과 | 솔로 변환 제안 |
|-------------|-----------|----------------|
| 자장가 (BD_LULLABY) | 범위 내 적 수면 확률 | 그대로 유지 — **범위 수면(CC)** 스킬로 솔로 사용 가능 |
| 심연속으로 (BD_INTOABYSS) | HP·SP 드레인 장판 | **광역 흡혈 장판** — 자신 회복 효과로 바꿔 솔로 생존기 |
| 울부짖는 로키 (BD_ROKISWEIL) | 범위 내 침묵(스킬 봉쇄) | **범위 침묵** — 몬스터 스킬 봉쇄. 원작 효과 그대로 적 대상 |
| 영원의 혼돈 (BD_ETERNALCHAOS) | 대상 DEF 0 + 저주 + 장비 저하 | **복합 디버프** — DEF 감소 + 이동속도 감소 조합 |
| 불사신 지그프리드 (BD_SIEGFRIED) | 범위 속성 저항 증가 | **자기 속성 저항 강화 버프** — 약점 속성 보완 수단으로 활용 |
| 김서방 돈벌었네 (BD_RICHMANKIM) | 범위 아이템 드롭률·EXP 증가 | **아이들 RPG에 최적**: 자기 드롭률+EXP 버프 (바드/댄서의 차별점 유지) |
| 전장의 북소리 (BD_DRUMBATTLEFIELD) | 범위 DEF·MDEF 증가 | **자기 DEF 대폭 강화 버프** — 강화형 수비 쿨다운 |
| 니벨룽겐의 반지 (BD_RINGNIBELUNGEN) | 범위 내 무기 추가 피해 방어 무시 | **자기 공격에 방어 관통 부여** — 높은 DEF 몬스터 공략기 |

### B-3. 기타 멀티 의존 기능 재설계 (2종)

| 직업 | 스킬 | 원작 | 솔로 변환 제안 |
|------|------|------|----------------|
| 몽크 | **진기주입** (MO_KITRANSLATION) | 자신의 정신구(Spirit Sphere)를 파티원에게 전달 | **정신구 폭발 강화**: 사용 시 정신구를 소모해 즉시 HP·SP 회복 (Lv에 따라 흡수율 증가). 또는 "일시적으로 정신구 최대 보유 수 +1" |
| 알케미스트 | **포션 피쳐** (AM_POTIONPITCHER) | 포션을 파티원에게 던져 회복 | 원작도 자기 자신 대상 가능. **자기 즉시 힐**로 단순화. 파티원 투척 문구 제거 |

## C. 텍스트 수정만 필요 (코드 변경 없음, 16종)

> 아래 스킬들은 원작에서 파티 범위 적용이 가능하나, 혼자서도 자기 자신에게 정상 작동함.  
> 실제 로직 변경 없이 스킬 설명(desc)에서 "파티원" / "범위 내 아군" 표현을 "자기 자신" 또는 삭제.

| 직업 | 스킬들 |
|------|--------|
| 복사 | 블레싱, 민첩성 증가, 민첩성 감소, 안젤루스 |
| 프리스트 | 임포시티오 마누스, 수프라기움, 마니피캇, 글로리아, 생츄어리, 아스페르시오 |
| 블랙스미스 | 아드레날린 러쉬, 웨폰 퍼펙션, 오버 트러스트 |
| 바드/댄서 | 악기다루기(BA_MUSICALLESSON), 춤연습(DC_DANCINGLESSON) 설명에서 "파티" 제거 |
| 크루세이더 | 디펜더, 신의 뜻 |

## D. 경제 시스템 단순화 (2종)

| 직업 | 스킬 | 원작 멀티 의존 요소 | 솔로 단순화 방안 |
|------|------|---------------------|-----------------|
| 알케미스트 | **러닝 포션** (AM_LEARNINGPOTION) | "포션 랭킹" 시스템 — 다른 플레이어가 만든 포션과 품질을 경쟁, 서버 순위가 성능에 영향 | 랭킹 부분만 제거. "포션 제조 성공률 증가 패시브"로 단순화. 스킬 Lv당 제조 성공률 +X% |
| 알케미스트 | **파머시** (AM_PHARMACY) | 위와 동일한 랭킹 체계 | "포션 제조 액션"으로 단순화. 랭킹 배율(최대 3배 효율) 제거, 기본 성공률 기반 제조로 처리 |

## 구현 우선순위 제안

1. **즉시 처리 (C)**  
   — 설명 문구만 고치면 됨. `DB_SKILLS`의 `desc` 필드 일괄 수정. 코드 리스크 없음.

2. **단순 제거 (A 중 노점개설·토키박스·클로즈컨파인)**  
   — `DB_SKILLS`에서 해당 스킬 엔트리 제거 또는 `type:"hidden"` 처리.

3. **생존기 재설계 (B-1: 헌신·희생·리저렉션)**  
   — 크루세이더와 프리스트의 핵심 차별성 스킬. 솔로에서도 "죽지 않는 직업" 정체성을 살릴 수 있어 구현 가치 높음.

4. **앙상블 재설계 (B-2)**  
   — 바드·댄서 직업 가치가 앙상블 없이는 많이 떨어짐. 솔로 버프/디버프 스킬 꾸러미로 변환하면 직업 차별성 복원 가능. 공수 균형 조정 필요.

5. **경제 단순화 (D)**  
   — 알케미스트 직업을 플레이어블하게 만드는 데 필요. 포션 랭킹 없이도 "자체 포션 제조" 루프를 만들 수 있음.
