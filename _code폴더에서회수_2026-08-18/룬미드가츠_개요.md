# 룬 미드가츠 연대기 — 프로젝트 개요

라그나로크 온라인 스타일의 브라우저 기반 텍스트 RPG.
단일 HTML 파일로 구현 (모듈화 시도 후 단일 HTML로 복귀).

## 핵심 시스템 (구현 완료 또는 진행 중)
- 틱 기반 자동 전투
- 직업/전직 시스템 (1차/2차/전승)
- 스킬 시스템 (액티브/패시브/토글 + 자동사용 토글)
- 스탯 공식 (ASPD, DEX 캐스팅, MDEF, HP/SP 리젠)
- NPC (상점, 제련, 카프라, 전직, 던전 입장, 교환)
- 퀘스트 시스템 (튜토리얼 + 전직 + A/B등급 22개)
- 버프/디버프 HUD
- 카드 시스템 (175개 구현 + 246개 미구현)
- 장착/인벤토리 / 카드 합성
- 저장/불러오기 (localStorage)
- 던전 접근 잠금 (unlockedMaps)
- 언어 장벽 시스템 (우탄족)

## 아키텍처
```
룬미드가츠_v8.html   ← 모든 게임 로직 + DB + UI 포함 단일 파일
```

## 알려진 버그 패턴
- `closeModal()`이 서비스 모달 열기 직후 호출되는 패턴 주의
- DB 섹션이 JS label block으로 선언되는 오류 주의
- 새 하위 객체(skillToggles 등) → 레거시 세이브 null 체크 필요

## 코드 작업 원칙
- **타겟 패치 방식** 선호 (대규모 재작성 ❌)
- 블록 위치 명시 (block-sys, block-game, block-ui, db-npcs)
- 함수 교체 시 교체 대상 명확히 표시
