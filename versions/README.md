# versions 폴더 — 버전 백업 규칙

게임 HTML 파일(`룬미드가츠_vX.XX.html`)은 셸(bash) 없이는 제가 직접 복사할 수 없을 만큼 큽니다(13,000줄+).
그래서 당분간은 다음 규칙으로 수동/반자동 백업합니다.

## 백업 파일명 규칙

```
룬미드가츠_v9.03_YYYYMMDD_HHMM.html
```

예: `룬미드가츠_v9.03_20260710_1830.html`

## 언제 백업하나

- 큰 작업(스킬 전면 개편, DB 대량 교체 등) **시작 전**
- 하루 작업 마무리 시점

## 현재 방식 (임시)

1. 작업 전, 현재 게임 파일(`..\룬미드가츠_v9.03.html`)을 이 폴더에 위 이름 규칙으로 복사
2. Windows 탐색기에서 복사(Ctrl+C) → 붙여넣기(Ctrl+V) → 이름 변경이 가장 빠름

## 셸(bash) 복구 후 전환 계획

- `git init`을 이 상위 폴더(Text_Rag)에서 실행 → 매 작업 단위로 커밋
- 이 versions 폴더의 스냅샷들을 초기 커밋 히스토리로 편입 가능
- 이후엔 `git log`, `git diff`로 버전 추적 (파일명 타임스탬프 방식보다 훨씬 정교함)
